# SKILLS.md

Agent skills vendored into `.claude/skills/` at project scope. Each one was downloaded outside the project, read in full (SKILL.md plus every script and hook), and copied in from a pinned commit. Exact commits and content hashes are in `.claude/skills.lock.json`. Install date for all entries: 2026-11-15.

To upgrade a skill: download the new commit outside the project, repeat the audit, copy it in, update the lock file, and add a line to `docs/DECISIONS.md`. Never run an upstream installer (`npx skills add`, `install.sh`, plugin marketplaces) against this repo.
